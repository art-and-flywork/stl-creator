# Name keychain

Type a name, pick a font, check it in 3D and download the STL. OpenSCAD
runs in the browser via WebAssembly; nothing is uploaded.

```bash
pnpm --filter keychain dev    # http://localhost:5173
pnpm --filter keychain test
```

The model lives in `models/keychain` at the root of the monorepo.
