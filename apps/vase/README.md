# Vase

Shape a vase with sliders, check it in 3D and download the STL. OpenSCAD
runs in the browser via WebAssembly; nothing is uploaded.

```bash
pnpm --filter vase dev    # http://localhost:5172
pnpm --filter vase test
```

The model lives in `models/vase` at the root of the monorepo.
