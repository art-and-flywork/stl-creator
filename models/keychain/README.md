# Name keychain

A name on a flat tag that follows the letters, with raised letters and a
ring for a key ring on the left, right or top. A short bridge runs from the
ring into the text, so the ring stays attached whatever the first letter is.

| Variable | Meaning |
| --- | --- |
| `name`, `font` | the text and its font (`"Family:style=Bold"`) |
| `text_size` | letter size in mm |
| `plate_thickness`, `text_height` | tag thickness and how far the letters stand out, mm |
| `border` | tag margin around the letters, mm |
| `hole`, `hole_side` | ring on/off; `"left"`, `"right"` or `"top"` |
